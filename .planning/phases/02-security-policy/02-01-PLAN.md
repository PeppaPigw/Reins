## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Agent -> Shell Adapter | Untrusted command strings from agent cross into subprocess execution |
| Network -> API Server | External network traffic reaches the HTTP API |
| Config -> Worktree Manager | User-configured commands from YAML cross into subprocess execution |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | shell.py exec() | mitigate | Replace create_subprocess_shell with create_subprocess_exec + shlex.split |
| T-02-02 | Information Disclosure | server.py bind | mitigate | Default to 127.0.0.1, require --expose-network for 0.0.0.0 |
| T-02-03 | Tampering | worktree_manager._run_command | mitigate | Replace create_subprocess_shell with create_subprocess_exec + shlex.split |
| T-02-04 | Tampering | config/hooks.py shell=True | accept | Hooks are user-configured local commands (analogous to git hooks); documented as accepted risk |
</threat_model>
