<objective>
Embed reins_version in all persisted artifacts and implement the event schema versioning system with upcaster registry.

Purpose: Enables forward-compatible replay of events across Reins upgrades. Without version embedding, migration tooling cannot determine which version produced an artifact. Without upcasters, schema changes break replay.

Output: EventEnvelope gains a `reins_version` field, StateSnapshot gains a `reins_version` field, UpcasterRegistry provides chain-based event payload transformation at read time, and hypothesis is added to dev dependencies for later use.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Disk -> Memory | JSONL files read into EventEnvelope objects; upcasters transform untrusted payload data |
| Snapshot file -> Memory | JSON snapshot files loaded and deserialized |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | EventJournal JSONL files | accept | Existing SHA-256 checksum per event detects payload tampering; upcasters operate on validated events only |
| T-01-02 | Information Disclosure | reins_version in persisted files | accept | Version string is not sensitive; aids debugging and migration |
| T-01-03 | Tampering | Upcaster registry injection | mitigate | Registry is module-internal singleton; no external registration API exposed. Only code within the reins package can register upcasters. |
| T-01-04 | Denial of Service | Malformed schema_version in event | mitigate | `event_from_dict` uses `data.get("reins_version", "unknown")` — graceful default. Upcaster range iteration bounded by current_version (small int). |
</threat_model>
