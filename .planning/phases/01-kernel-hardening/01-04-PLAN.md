<feature>
  <name>Reducer Property-Based Tests</name>
  <files>tests/test_reducer_properties.py</files>
  <behavior>
    - Replay invariant: For any sequence of events E1..En, reducing from empty state incrementally (s0->s1->...->sn) produces the same final state as reducing from empty state with the full sequence replayed.
    - Purity: reduce(state, event) never mutates the input state object. After calling reduce, the original state's fields are unchanged.
    - Graceful unknown events: reduce(state, event_with_unknown_type) returns a state equal to the input (no crash, no mutation).
    - Valid transitions: For known event types, the resulting status is always a member of RunStatus enum.
    - No exceptions: reduce never raises an exception for any valid EventEnvelope (regardless of payload content, within type constraints).
  </behavior>
  <implementation>
    Use hypothesis strategies to generate valid EventEnvelope instances covering all 17 event types plus unknown types.
    Use RuleBasedStateMachine for stateful testing that builds up state over many events and checks invariants at each step.
    Use @given decorator for stateless property tests (purity, replay).
  </implementation>
</feature>
